# DualSub TV

一个给 Android TV 用的视频播放器，核心是做一件别的播放器基本不做的事：**同时挂两路字幕**。

## 它解决什么

用电视看外语片，字幕是刚需。但绝大多数 TV 播放器只给你**一路**字幕，于是：

- 想看中英双显 —— 得先用工具把两路字幕合成一条，还得处理时间轴对不齐；
- 片子在 NAS 上 —— 播放器自带的网络浏览往往难用，甚至不认 SMB；
- 内嵌字幕导不出来 —— 想换个字号、挪个位置都没得调。

DualSub TV 就是冲这几件事来的：**主、次两路字幕各自独立**，来源、字号、位置、时间偏移全都分开调；
片源直接读局域网里的 NAS、WebDAV，或者三家云盘。

## 主要功能

**双字幕**

- 主字幕、次字幕各一路，可以一路用视频内嵌轨、另一路用外挂文件，也可以都是外挂
- 两路都能单独调：字号、颜色、描边、底部距离、时间偏移
- 文本字幕**自己画**（不交给播放器），所以中文不会渲染成方框
- PGS / DVD / 蓝光这类**图片字幕**只能占主字幕位（位图没法自己画）
- 每个视频记住上次用的哪两路字幕

**片源**

- 本机与 U 盘（走系统媒体库）
- 局域网 **SMB** 共享 —— 进入即扫描，**不需要事先知道共享名**
- **NAS 按品牌接入**：飞牛 / 群晖 / 威联通 / 绿联，默认端口已预填并自动探测
- **WebDAV**：AList / Nextcloud 之类
- **DLNA** 媒体服务器
- **云盘**：夸克 / 百度 / 阿里（扫码登录）

**AI 字幕**

- 用 OpenAI 兼容接口把外语片译成字幕（默认阿里云百炼）
- 可以整片批量生成，也可以边看边实时翻译
- 配置做成「电视显示二维码、手机扫码填 Key」—— 用遥控器敲 API Key 是折磨

**界面**

- 深墨夜景 + 无色玻璃 + 单一香槟金强调色，三米外看得清
- 全程方向键操作，返回键逐层退出，破坏性操作要确认
- **退出播放回到刚才那个目录**，不用重新一层层点进去

## 安装

需要 Android 6.0（API 23）以上。

```powershell
.\gradlew.bat :app:assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## 已知限制

- **多声道会被下混成立体声** —— 拿不到 Dolby / DTS 直通（Atmos 等），这是播放引擎在部分电视上的限制
- 图片字幕只能挂主字幕位；DLNA 片源的内嵌字幕也只有主字幕读得到
- 复杂 ASS 特效（矢量绘图、复杂动画组）表现不如专业字幕渲染器 —— 这是"中文不出方框"换来的
- 网络位置的密码明文存在应用私有目录（非 root 设备其他应用读不到）；介意就用只读账号
